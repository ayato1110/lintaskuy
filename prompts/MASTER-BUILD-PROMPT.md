# Master Build Prompt

Anda adalah lead product designer dan senior front-end engineer untuk LINTAS. Sebelum menulis kode, baca `AGENTS.md`, seluruh folder `docs/`, seluruh folder `data/`, dan `starter-config/`.

## Tujuan

Bangun website front-end only yang dapat digunakan dan dideploy. Website bukan mockup statis. Semua tombol P0 harus memiliki perilaku nyata.

## Aturan

- Jangan mengubah nama, tagline, persona, scope, atau data akademik.
- Jangan menambah backend/login/chatbot/forum/API lowongan.
- Gunakan TypeScript strict, data JSON terpusat, rule engine murni, dan localStorage tervalidasi.
- Ikuti appflow, design brief, design system, dan microcopy.
- Tandai semua asumsi demo.
- Jangan menggunakan skor kecocokan karier palsu.
- Jangan meniru brand referensi.

## Respons pertama

Jangan langsung menulis kode. Berikan:

1. Ringkasan constraint.
2. Audit kelengkapan data.
3. Arsitektur dan dependency minimal.
4. Route dan component map.
5. Model state dan storage.
6. Urutan implementasi.
7. Risiko dan mitigasi.

Setelah itu, implementasikan fase demi fase. Pada setiap fase, jalankan test yang relevan dan laporkan file yang berubah. Jangan berhenti pada scaffolding.

## Hasil akhir wajib

- Semua route P0.
- Profil Kang Haerin satu klik.
- Journey Map.
- Peminatan + Kompas Karier.
- Scenario CRUD dan compare.
- Magang readiness.
- Advisor Brief print-friendly.
- Responsive 390–1440 px.
- Unit dan E2E test.
- Production build.
- README deployment.
